### Project Overview

This project is the official website for The Kingdom Trybe, built using React.js and Vite.

### Project Setup

1. Clone the repository:

  ```bash
   git clone https://github.com/systems-a/the-kingdom-trybe-frontend-v2.git
  ```

2. Install dependencies:

  ```bash
   npm install
  ```

3. Start the development server:

  ```bash
   npm run dev
  ```
